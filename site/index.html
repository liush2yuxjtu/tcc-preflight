tcc-preflightGrant every macOS privacy permission before your Mac mini agent goes headless.

The pain: a headless agent hits a hidden Camera / Screen Recording / Accessibility prompt that nobody can click — and silently fails.

git clone https://github.com/liush2yuxjtu/tcc-preflight && cd tcc-preflight && make && bin/tcc-preflight
  1. Run tcc-preflight on the Mac with a monitor attached; approve each prompt.
  2. Plug in the HDMI dummy plug.
  3. Go headless. Re-check anytime with tcc-preflight --check (never prompts).
